## Why this exists

Job seekers keep a Word resume, a Canva portfolio, and a GitHub README that never match. Recruiters want both a live link and a scannable PDF. ATS systems want clean formatting.

FolioX is the source of truth for that. Fill one profile, or upload an existing resume and let it autofill, and you get:

- A mobile-ready portfolio at [foliox.me/username](https://foliox.me)
- An ATS-friendly resume PDF from the same data
- Updates in one place, not three

Built for job seekers, developers, designers, freelancers, and students.
